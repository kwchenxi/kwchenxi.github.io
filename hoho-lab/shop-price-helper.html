核心功能

扫码查价

扫描商品条形码，立即显示商品价格和库存。

扫码录入

扫描条形码自动获取商品编码，补充图片、描述和价格即可入库。

商品管理

查看、搜索、编辑、删除商品，库存一目了然。

购物车

将商品加入购物车，自动累计总额。

快速开始

  1. 1微信开发者工具导入项目，开通云开发，将环境 ID 填入 app.js
  2. 2创建 products 商品集合（条码 / 名称 / 价格 / 库存 / 图片）
  3. 3部署 login 与 barcode-lookup 两个云函数
  4. 4点击编译预览，扫码即用
