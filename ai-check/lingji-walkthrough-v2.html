基准状态

会议室预订 · 默认窗口状态

顶部筛选栏（日期、时间、区域、标签、搜索）+ 会议室卡片列表（3列网格）+ 左侧导航栏。窗口约 1280×800px。

L1

响应式布局

严重 响应式

#1 小窗口下筛选栏被截断/溢出

▼
位置顶部筛选栏（日期、时间、区域、标签、搜索）
表现窗口缩小时，日期和时间控件仍占据大量宽度，右侧"全部区域/全部标签/搜索会议室"被挤出可视范围，且无水平滚动条提示。
影响用户在小窗口下无法完整使用筛选条件，搜索入口不可见。
规范基准：Lingee Spacing Token 要求组件间距使用 x-small(8px) 或 medium(16px)。筛选栏应自适应容器宽度。
建议：窄宽下筛选栏自动换行；或将区域、标签、搜索收纳为"筛选"抽屉；或支持横向滚动并显示明确滚动提示。
严重 响应式

#2 小窗口下卡片仍强制3列，内容被严重压缩

▼
位置会议室卡片列表区域
表现窗口变窄后仍保持3列布局。容量信息出现"可容/纳4人"异常换行，会议室名称被截断为"云卷亭（B8..."。
规范基准：Lingee Spacing 基于 4px 网格，卡片间距应为 medium(16px) 或 large(20px)。响应式应 3列→2列→1列。
建议：增加响应式断点。容量信息设置 white-space: nowrap，作为不可拆分的 inline-flex 元素。
中等 响应式

#4 左侧导航在小窗口下未折叠

▼
表现左侧导航始终完整显示，在小窗口下仍占据较大宽度，导致右侧内容区严重不足。
规范基准：Figma Sidebar 定义了 3 个 scene=web 变体（chat/dev/Management），应有折叠态。
建议：窄屏时自动折叠为图标栏，或提供收起按钮。
中等 响应式

#5 会议室名称/地点被截断，可读性不足

▼
表现"云卷亭（B8..."、"B栋..."。虽有省略号，但可读信息不足。
建议：增加 title tooltip；或允许名称两行显示；窄屏时优先保证地点信息完整。
中等 响应式

#6 超宽状态下卡片过度拉伸，空白过多

▼
表现全屏/最大化后卡片横向宽度很大，信息与"立即预订"按钮距离很远，信息密度偏低。
建议：设置卡片 max-width；超宽时增加列数至4列；或将列表容器 max-width 并居中。
中等 响应式

#10 容量信息异常换行（"可容/纳4人"）

▼
表现"可容纳4人"被拆为"可容/纳4人"，"可容纳14人"被拆为"可容/纳14/人"。
建议：white-space: nowrap，图标+文本整体作为 inline-flex 不可拆分元素。
L1

设计规范对照

严重 规范对照

#3 预订界面打开为独立大窗口，不符 Dialog 规范

▼
表现打开的是独立窗口（约 1080×700px），而规范要求弹窗宽度为小 460px / 中 640px / 大 720px。
规范基准：Lingee Dialog width: small=460px / medium=640px / large=720px。当前 1080px 超出最大规格 50%。
建议：改为居中 Modal 弹窗（推荐 720px 大尺寸）；若需完整窗口，应在规范中声明例外。
中等 规范对照

#8 "立即预订"按钮高度疑似偏小

▼
表现按钮视觉高度约 22-24px，未达到 md 规格的 28px。
规范基准：Lingee Button size: sm=24px / md=28px / std=32px / lg=36px。实测约 22-24px，偏差 4-6px，低于最小规格 sm。
建议：确认实际 CSS height/padding，至少对齐 md（28px）。
中等 规范对照

#9 新建会议右侧时间轴信息理解成本高

▼
表现左侧表单显示 19:30-20:30，右侧时间轴出现 01:45/19:45 等红色标记，并有 GMT-10/GMT+8 两列。
建议：突出当前会议时间块，弱化非当前时区信息。
轻微 规范对照

#16 AI推荐标签尺寸偏小，未对齐 Tag 组件

▼
表现"AI推荐"标签高度较小，更像自定义徽标而非标准 Tag。
规范基准：Lingee Tag 支持 sm/md/lg 三种尺寸，shape 为 pill 或 rounded，color 为 info/primary/success/warning/danger 六选一。
建议：对齐 Tag 组件规范的某一尺寸规格。
轻微 规范对照

#14 Segment 选中态区分度不足

▼
表现选中态主要依赖蓝色边框和文字颜色，对比度不强。
规范基准：Lingee Tabs variant 包含 segmented/solid/outline/underline 四种。当前类似 segmented 但选中反馈偏弱。
建议：选中项增加背景填充，与未选中项形成更明显的视觉差异。
L2

空状态与错误状态

轻微 状态

#12 搜索无建议提示，直接过滤为空

▼
表现输入"云"后直接显示"暂无可用会议室"，无搜索建议或匹配提示。
规范基准：Lingee Select 支持 showSearch + filterOption，应有搜索建议交互。Lingee Empty 组件提供空状态规范。
建议：增加搜索建议下拉，或在空结果时提示"未找到包含'云'的会议室"。
轻微 状态

#15 快速操作时下拉面板残留打开

▼
表现连续点击不同筛选控件后，前一个下拉面板可能仍停留在界面上。
建议：切换其他筛选条件时自动关闭已打开的 Select 面板。
轻微 状态

#17 滚动条样式较轻，加载反馈不明显

▼
表现滚动后加载了更多会议室，但滚动条视觉存在感弱。
建议：增加 loading 状态动画（Lingee Spin 组件）。
轻微 状态

#18 新建会议底部操作区与内容区分隔不清晰

▼
表现"取消/保存"按钮贴近窗口底部，下方表单内容只露出一部分。
建议：底部操作区固定（sticky），内容区独立可滚动，两者有清晰分隔线（Lingee Divider）。
L2

焦点与键盘导航

轻微 焦点

#11 搜索框焦点状态不够明显

▼
表现输入后搜索框没有明显的主色描边，焦点感较弱。
规范基准：Lingee Input focus 态应为 border: #495DFF 1px（主色描边），默认态 border: rgba(0,0,0,0.08) 1px。
建议：对齐 Input 聚焦态规范，增加主色描边。
中等 焦点

#7 日期输入框可选中但不可编辑，交互反馈不一致

▼
表现日期文本可被选中，视觉上像可编辑输入框，但键盘输入不生效。
规范基准：Lingee DatePicker trigger height=40px, border default rgba(0,0,0,0.08), hover/open #495DFF。只读态应禁用文本选中。
建议：禁用文本选中（只读态），或支持键盘编辑。
轻微 焦点

#13 区域选项多但缺少搜索能力

▼
表现区域下拉有多个选项，面板一次只显示少量，需滚动查找。
规范基准：Lingee Select 支持 showSearch 属性，开启搜索可显著提升长列表可用性。
建议：使用可搜索 Select 组件（showSearch）。
